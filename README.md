
# Software meiner Masterarbeit

Was ist enthalten?
------------
- ein Recommender für die Software Inception, basierend auf PropsDE
- Skripte, die einen Workflow handeln, der u.a. folgende Schritte enthält:
  - generieren und abrufen einer Stichprobe von Büchern aus der Deutschen Nationalbibliothek
  - Handling von Dateien (Inhaltsverzeichnisse, Buchscans, Textstellen, Abbildungen) zwischen Zotero, Inception und Festplatte
  - generieren von Propositionen basierend auf Annotationen, die in Inception gemacht wurden
- ein Skript zur statistischen Auswertung meiner Daten
- vermutlich auch einige Dateien, die nicht mehr nötig sind

Wie kann ich die Software selbst nutzen?
------------
Wahrscheinlich noch gar nicht. Es ist geplant, in Zukunft den Code so zu überarbeiten und zu dokumentieren, dass die Software auch von anderen genutzt werden kann.
